# One-frame drawing / one-frame rest

The current skill requires a scene-level `start` and `end`, actual source dimensions/FPS/duration, and at least three `drawings` anchored to actual scene elements or their different edges. See `demo-scene.json` for a complete example. Each drawing requires `target` (specific visible element/edge), `target_bounds: [left,top,right,bottom]` (tight inspected output-pixel bounds of that element/edge), and `strokes` with explicit `points`, optional `width`, `color`, `seed`, `boil` and `reposition`. Set `background` to the actual video path for an edit. Keep source duration/FPS/dimensions unchanged.

Timing is exact at output FPS: first eligible frame = ceil(start × FPS). Relative frame 0 shows drawing 0; frame 1 has NO doodle pixels; frame 2 shows drawing 1 somewhere else; frame 3 has NO doodle pixels; frame 4 shows drawing 2, and so on. End is exclusive. Every line and shape has exactly ONE frame of life. Entire drawings cut away together. No neighboring active frames, draw-on, fades, crossfades, motion between locations, lingering contours or trails.

Drawing groups are selected in authored order. Arrange them so every successive group, including last→first, has a different shape and a different meaningful target or target edge. Do not just shift the same face contour by a few pixels. Geometry is freshly varied from seed + absolute frame index on reuse; a template is not a held or repeated rendered frame. Use sparse arcs, loose lines, angular fragments or simple doodle shapes. Do not recreate unrelated reference typography, grading or transitions.

Keep hand roughness VERY LIGHT: default `boil` 0.65px at width1080 plus 0.12px fine irregularity, `reposition` 8px for local variation within each authored region. Position changes come from switching meaningful targets/edges, not random empty regions. Keep variation inside a safe margin around each target. Width defaults to 2.4px × width/1080. Explicit values use output pixels. Keep warm off-white narrow cores, no glow/shadow. Use `mode: flash` or omit it. Per-stroke timing overrides are rejected so they cannot fill rest frames.

Flash geometry and alpha are constant within the one-frame exposure. All shutter samples therefore coincide. Never average different frame drawings across time or blur a flash into its rest frame. The renderer returns an exactly zero RGBA overlay on every rest frame and outside the interval. MP4 compression can affect decoded source pixels slightly; test overlay alpha for the exact blank guarantee.

The renderer uses explicit authored geometry, without segmentation/tracking/OCR. Inspect the scene and keep all flashes clear of important face, text and object details. It copies source audio unchanged and adds no other scene edits. MP4 is composited, not an alpha export.

Target metadata is an execution contract, not detection. The renderer rejects missing labels/bounds, invalid bounds and stroke points farther than 5% of frame width from their target rectangle (plus their local variation budget). This coarse check does not replace visual review. Do not label the full frame as a target to bypass it. Inspect the real frame to confirm attachment and clearance. The neutral example is only a schema illustration; its named targets are not visible objects on a plain field. Reauthor all geometry/bounds for new footage.
