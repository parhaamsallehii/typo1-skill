# طرح پلانِ مبتنی بر محتوا

قبل از ساخت، یک JSON یا جدول کوتاه ثبت کن: source,start,end,fps,palette,head_track و shots. هر shot شامل start,end،speech_evidence (متن و منبع/زمان آن)،idea،hero،action،material،entry،hold،exit،asset_provenance و labels باشد. labels پیش‌فرض خالی است؛ فقط برچسب کوتاه عملکردی مجاز است.

نمونهٔ فرضی (گفتار منبع واقعی معرفی نشود): مفهوم «پردازش چند فایل» → دو کارت کاغذی وارد صف می‌شوند، یک مسیر به یک کارت خروجی می‌رسد، روی خروجی تیک می‌آید. زمینه کرم، خط زرشکی، حداکثر3کارت، بدون جملهٔ زیرنویس.

برای هر تغییر گفتار الزاماً پلان را عوض نکن؛ اگر یک مفهوم ادامه دارد همان آبجکت را تکامل بده. کارت آمادهٔ یکسان را برای موضوعات نامرتبط تکرار نکن. رفرنس‌های تصویری را برای ظاهر بخوان و متن/شخصیت/امضای آن‌ها را کپی نکن. فایل موشن نهایی ورودی compositor است؛ compositor به تنهایی بخش خلاقه را تولید نمی‌کند.
