# Native After Effects workflow

Use this route only with a compatible Windows After Effects host and installed effects. The bundled `assets/native/LiquidGlass.aex` is a Windows x86-64 effect, identified by its embedded name as `TFM LiquidGlass`. Do not execute it as a standalone program or claim Linux Pillow/FFmpeg can load it. Preserve the supplied binary; verify host/plugin compatibility through an actual render. Deep Glow 2 is a separate required native plugin and is not bundled here.

1. Import clean presenter footage, retain its audio, and normalize its displayed rotation, crop, scale, timing and grading in a source precomp. Exclude shadow-ramp, watermark, captions and other foreground elements from the refraction source.
2. Set final composition dimensions/fps from the edit. At 1080×1920, center the pill at `(540,1356)`, height `82`. Use Rectangle Path dimensions for width, never X scaling that stretches caps. Use maximum corner radius: `min(width,height)/2`. Width is shaped text advance/ink bounds plus `52` horizontal pixels; reference text «فریلنسر برای کسب و کار» produces approximately `569` width with the bundled regular face at reference font size `78`.
3. Apply the supplied Liquid Glass effect to the pill and bind its **Source Layer** to the clean presenter source. Mask the effect to the pill silhouette. Keep source and mask coordinate systems aligned in composition space. Any required parenting must be compensated so the pill stays in its fixed screen placement while the original video crop/zoom changes. As the pill moves or resizes, reveal the current frame underneath at that screen location, not a frozen crop or a texture stretched with the shape.
4. Compare `assets/references/style.png`, `placement.jpg` and `motion-preview.mp4`. Native control labels inspected in the binary include `Source Layer`, `Refraction`, `Glass Body`, `Thickness (Blur)`, `Tint Color`, `Specular Highlights`, `Light Angle`, `Light Color`, `Highlight Distance`, `Amount`, `Edge Blur` and `Shadow`. The references are rendered pixels and do not expose the original numeric effect settings. Do not invent numeric settings and call them recovered values. Tune available controls to the reference's dark transparent body, soft edge refraction, bright upper-left rim, weak lower rim, and rounded ends. Keep a soft dark shape shadow below the glass; avoid double-counting plugin and layer shadows.
5. Place a separate Persian text layer above the pill. Use `Traditional Arabic` regular from `TRADO.TTF` by default; preserve the supplied `TRADBDO.TTF` bold as an available variant, not a silent replacement. Use an RTL/Persian composer, size about `78` reference pixels, white `#FFFFFF` fill, black `1` reference-pixel stroke, no tracking between joined glyphs. Center actual ink bounds vertically/horizontally rather than the font's empty line box.
6. Apply text effects in the requested order: (a) black Drop Shadow, Distance `3.5`, Opacity `100%`, Softness `0`; (b) black Drop Shadow, Distance `5`, Opacity `100%`, Softness `14`; both offset down-right (45° vector, about 135° in AE Drop Shadow convention; verify visually); (c) Deep Glow 2 Radius `1000`, Exposure `0.01`; (d) weak hand-drawn contours; (e) fine-scale Turbulent Displace. Weak contour defaults of amplitude roughly `.3–.5` px and fine scale `7–12` px are visual starting points, not measured native controls. Keep joined glyphs and dots legible and glyph centers stationary. Use no position/scale/opacity entrance, exit or text-change animation.
7. Create one persistent pill per continuous requested subtitle block. For each caption cut `T`, key the source text as a hold/discrete change exactly at `T`. Key pill width at `T−8/fps` and `T`, old evaluated width → next shaped width. Keep its center, height, corner smoothness and text transforms constant. Preserve nonzero incoming size velocity; plain linear keys match the supplied expression's velocity assumption. Put `scripts/ae-size-expression.jsx` on Rectangle Path Size; it springs only width after arrival keys. Do not also use elastic easing.
8. If a prior spring is still active at the next anticipation key, set that key's width to the previous evaluated width so the new base motion starts continuously. For pairs too close to fit eight frames, regroup/re-time when authorized, or shorten only to the available interval and disclose it. Never create keys outside the requested block or across a cut/gap.
9. Cut the complete subtitle pair on/off at the requested block boundaries. Do not animate from zero width or fade at those outer boundaries. At a final leftover cue of one or two words, retain that text and resize normally. Source audio and external watermark/ramp remain independent.
10. Render frames before anticipation, immediately before/at/after each text cut, peak bounce and settled hold. Verify native effects execute and identify missing plugins honestly. Preserve the editable composition and validate the exported video.
