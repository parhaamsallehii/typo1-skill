# قالب صحنه

`demo-scene.json` یک تست نمایشیِ بی‌صدا با تصویر ثابت است. عبارت‌های آن تألیفی هستند و نباید ترنسکریپت مجری فرض شوند.

ساختار:

```json
{
  "width":1080,"height":1920,"fps":30,"duration":5,
  "background":"source.mp4",
  "speech_evidence":{"file":"verified-timing.json","method":"actual audio review or available recognizer"},
  "events":[{
    "start":0.2,
    "top":["در دنیای","محتوا"],
    "bottom":["خلاقیت","می‌درخشد"],
    "speech_verified":true,
    "cues":[0.266667,0.4,0.966667,1.266667],
    "exit_start":2.0
  }]
}
```

اعداد این مثال فقط قالب‌اند، نه زمان گفتار واقعی. پرچم `speech_verified` را بدون شنیدن/تأیید کلمات true نکن. رندرر حضور اطلاعات را کنترل می‌کند، نه صحت ادعای متن/هم‌ترازی را. در نبود تشخیص گفتار، فقط برای تست تألیفی `demo:true` بگذار و همین محدودیت را بگو.

`top` و `bottom` هرکدام دقیقاً دو رشتهٔ غیرخالی دارند؛ ترتیب آرایه، ترتیب خواندن فارسی است. رشتهٔ اول سمت راست و دومی سمت چپ قرار می‌گیرد. بخش اول `bottom` کلمهٔ کلیدیِ هایلایت‌شده است. تقسیم فقط در مرز کلمه؛ نیم‌فاصله و اتصال حروف حفظ شود. سایر زبان‌ها/چپ‌به‌راستِ ترکیبی باید مستقل بررسی شوند؛ وارونه‌کردن دستیِ Unicode ممنوع است.

`cues` چهار شروعِ مطلق به ثانیه است: بالا۱، بالا۲، پایین۱، پایین۲. برای اجرای واقعی لازم است؛ در تست، شروع‌ها از پروفایل مرجع گرفته می‌شوند. `exit_start` شروع خروج مشترک است؛ خروج پیش از رسیدن پایهٔ آخرین بخش مجاز نیست؛ بانسِ اکسپرشن ممکن است هم‌زمان با خروج والد هنوز در حال افت باشد. `highlight_start` اختیاری است؛ پیش‌فرض،۱۲ فریم مرجع بعد از کلید پایین است. برای گفتار متفاوت مکث و cueها را آگاهانه تطبیق بده، نه تقسیم مساوی زمان.

`center_x`، `top_y` و `bottom_y` در هر رخداد، مختصات نرمال‌شدهٔ مراکزند؛ برای جایگذاری روی مجری جدید تنظیمشان کن. فونت‌ها/پالت و مسیرها از پروفایل همراه می‌آیند. متن‌های خیلی بلند به‌طور یکپارچه کوچک می‌شوند؛ پیش از قبول خروجی، خوانایی و نسبت ظریف/بولد را بازبینی کن. هیچ کشیدگیِ افقیِ حروف اعمال نمی‌شود.

ابعاد و FPS باید با ویدیو یکسان باشند؛ رندرر کشیدن/کراپ یا تغییر FPS را رد می‌کند. مدت را از خود منبع بگیر؛ ویدیو را برای تطبیق با تست۵ثانیه‌ای قطع نکن. اگر منبع کوتاه باشد، ابزار خطا می‌دهد و فریز/لوپ مخفی نمی‌سازد. صدای منبع بدون بازکدگذاری کپی می‌شود. تصویر ثابت و رنگ `#RRGGBB` برای تست مجازند. مسیر نسبی نسبت به JSON حل می‌شود.

خروجی MP4 کامپوزیت‌شده است؛ شفاف نیست. گزارش کنار ویدیو شامل سایز واقعی فونت، cueها و شروع/پایان خروج است. اجرای کدی معادل رندر بومی افتر افکت و تنظیمات بازیابی‌شدهٔ پروژه نیست.

بانس تمام ورودها و رشد هایلایت از اکسپرشن قطعیِ کاربر محاسبه می‌شود. مقدارهای پایهٔ پروفایل بدون اُورشوت دستی‌اند. FPS واقعیِ صحنه برای frameDuration/10 به کار می‌رود. موشن‌بلر۱۸۰/۰/۱۶/۱۲۸ از اسکرین‌شات کاربر است؛ آن را تنظیم حدسی معرفی نکن.
