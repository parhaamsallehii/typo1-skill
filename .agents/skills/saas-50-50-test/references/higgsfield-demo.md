# Scope of the five-second example

The user explicitly selected a **full-frame motion-only test**, because the three
provided files contained no presenter. It is silent, with a 1080×960 viewport that
also fits the bottom pane of a 1080×1920 production output. Do not describe this
example as a presenter composition or as verified speech synchronization.

The illustrated flow is image input → named camera control → video preview.
Primary product references consulted:

- https://higgsfield.ai/creator-hub/help-center/ai-models/how-do-i-use-dop
- https://higgsfield.ai/camera-controls

The official guide describes adding a keyframe image, choosing a DoP preset,
optionally describing the scene, and generating. The control catalog lists
Dolly In, Static and 360 Orbit. The example is a custom explanatory UI, not an
exact copy of the current website interface. No Higgsfield account, paid credits
or generation call was used. Its car image was made with the host image tool;
the apparent motion preview is an authored image transform, not a real DoP result.

The source references are the style target. The new demo is a tested seed whose
appearance and timing may be revised after user review; it is not labeled approved.
