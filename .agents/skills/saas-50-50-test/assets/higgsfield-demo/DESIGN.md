# SaaS 50.50 Test — Reference Matched UI Motion

## Style Prompt
Airy white product-motion in the language of the three provided reference videos: small floating white beveled capsules, realistic soft shadows, glass layers, deliberate black type, subtle pastel gradients and occasional stronger multicolor episodes. Stage UI in perspective with a shared virtual camera, then move through an object into the next state. Use tight cursor-led interactions and a fan of cards. Match the bright product-film reference, not the earlier engraved collage.

## Colors
- #f5f5f7 — cool near-white stage
- #ffffff — raised UI planes
- #12131b — primary ink
- #6a6e7b — secondary ink
- #eb4c8f / #9671f6 / #60bde9 — selection and gradient accents

## Typography
Vazirmatn, 400/600/700, for both Persian UI and Latin product labels. Large short Persian state headings, small but readable actual UI. No calligraphic Traditional Arabic or Avangard display type. No typography stretched to fit.

## Layout
Motion panel is 1080×960 — exactly the lower half of a 1080×1920 deliverable. This user-selected five-second demo exports the motion panel alone, with no presenter and no audio. Production split remains top 50% main presenter, bottom 50% speech-aligned animation.

## Motion
0–1.45s: image choice as a small raised white input capsule; a cursor selects the image.
1.45–2.70s: camera-move controls shift toward camera with perspective and a compact gradient-selected Dolly In chip.
2.70–5.00s: expand through the selected input to a card fan showing source, motion control and illustrative video preview. Camera settles; readable final heading holds.
Use 0.3–0.65s tail-heavy ease-outs; 0.25–0.4s accelerating zoom handoffs. No constant breathing title, no random flying UI, no fabricated analytics. CSS perspective is a UI camera, not a Blender mesh scene.

## What NOT to Do
No dark generic tech dashboard, engraved collage, hard flat black shadow, unrelated footage, fake actual Higgsfield screen recording, made-up generation statistics, tiny unreadable paragraphs, or jump cuts. The photographic car is a generated demo input; a parallax preview is not claimed to be a real Higgsfield output.
