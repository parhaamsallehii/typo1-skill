# Render workflow

## Runtime

Python 3, Pillow with RAQM, NumPy, and fontTools are needed. FFmpeg is required for video. Run `python scripts/render_type.py --check` from the skill directory. If dependencies are absent, use only permitted installation tools. Never render disconnected Persian when RAQM is missing. A skill does not grant editing-app, software, or network access.

## Title or overlay

Use absolute task output paths:

```bash
python scripts/render_type.py --scene /absolute/path/scene.json --output /absolute/path/title.mp4 --poster /absolute/path/poster.png
```

A `.png` output is a still; `--time 1.5` chooses its timestamp. For alpha use background `transparent` and `.mov` (ProRes 4444) or `.png` (RGBA). Transparent MP4 is rejected. A matching `.layout.json` records resolved placement/timing. Default poster time is fully settled; inspect entrance frames separately. No audio is generated by this renderer. Video duration is rounded up to whole frames, by less than one frame when necessary.

## Existing-video composition

Inspect the source with FFprobe. Match dimensions/frame rate or explicitly preserve timestamps in a supporting engine. For variable frame rate, handle time base deliberately and verify sync. Preserve original audio unless asked otherwise.

1. Render an alpha overlay for the local interval.
2. Place it at the requested output-timeline start without changing frames outside the interval.
3. With FFmpeg account for stream timestamps, setpts, enable, eof_action=pass, and repeatlast=0. Do not let the final overlay frame persist beyond its end.
4. Preserve color treatment, audio, and metadata appropriately. Never overwrite the original.
5. Inspect start/middle/end, including exact first/last text visibility, and probe the output.

These are requirements, not a pre-executed command. Choose concrete commands from actual streams. A standalone title is not an edited version of the source video.

## Native editor

If a native After Effects or other project is requested, verify that software/automation is available. Use both fonts and the same layout/timing. Apply actual Deep Glow Exposure 0.02 only with the plugin installed. Map downward shadow to the native angle convention. Never rename JSON to pretend it is `.ffx`.

The bundled glow is a procedural visual recreation, not a pixel-identical Deep Glow implementation. Preserve this distinction in delivery.

## QA

Check glyph coverage, full text/order, joins/dots/half-spaces, fixed layout, rightward entrance start, alpha 0→1, gentle finish, hard downward 5-reference-pixel shadow, stable clipped texture, and faint glow. Review the contour boil at playback speed. Probe video dimensions/rate/duration/alpha. Check supplied speech times against real audio; demo staggering proves no transcription accuracy.
